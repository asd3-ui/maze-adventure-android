# متاهات المغامرة | Maze Adventure

لعبة متاهات مبنية باستخدام React Native وExpo Router، مع مراحل متعددة، خصوم، تلميحات، سمات بصرية، وحفظ التقدم محليًا.

## المتطلبات
- Node.js 20 أو أحدث
- npm
- Android Studio وAndroid SDK عند البناء محليًا (اختياري إذا استخدمت GitHub Actions)

## التشغيل محليًا
```bash
npm install
npx expo install --check
npm run typecheck
npx expo start
```

## بناء APK عبر GitHub Actions
1. ادفع التغييرات إلى فرع `main` أو افتح Pull Request إليه.
2. افتح تبويب **Actions** في GitHub واختر **Android APK**.
3. انتظر نجاح خطوات التحقق والبناء.
4. نزّل ملف `maze-adventure-android-apk` من قسم **Artifacts** في تشغيل workflow الناجح.

يمكن تشغيل البناء يدويًا من **Actions → Android APK → Run workflow**.

## ملاحظات
- يتم حفظ التقدم والإعدادات على الجهاز باستخدام AsyncStorage.
- مؤثرات الصوت غير مفعّلة حاليًا لأن ملفات الصوت الأصلية غير موجودة؛ تبقى اللعبة قابلة للعب مع الاهتزازات الاختيارية.
- يجب مراجعة سجل Actions بعد البناء للتأكد من نجاح الفحص النوعي وتجميع APK على Android.


## تحسينات أسلوب اللعب

- المتاهات تتضمن حلقات ومسارات بديلة حتى لا يفرض الوحش طريقًا مسدودًا.
- تظهر الوحوش بعيدًا عن نقطة البداية وبوابة الخروج، وتتحرك عبر الممرات الفعلية.
- اجمع الجواهر للحصول على نقاط إضافية، والتقط الدرع ليحميك من اصطدام واحد.
- أيقونة التطبيق مأخوذة من الصورة الموجودة في `assets/images/icon.png`.


### حركة الوحوش والمطاردة
- تتحرك الوحوش باستمرار حتى عندما يتوقف اللاعب عن الحركة.
- وحوش الصياد تتعقب موقع اللاعب الحالي وتسلك الممرات القابلة للمشي بدلًا من محاولة المرور عبر الجدران.
- تزداد وتيرة الحركة تدريجيًا مع تقدم المستويات؛ استخدم الفروع الجانبية والممرات البديلة لتغيير الاتجاه وكسب الوقت والوصول إلى المخرج.


## حملة المئة مرحلة والمتجر
- تحتوي الحملة على 100 مستوى قابل للفتح بالتتابع، مع متاهات تكبر وتزداد كثافة الأعداء وسرعتهم تدريجيًا.
- لكل مستوى اسم بيئة خاص به، وتتبدل لوحات الألوان بين البيئات مثل الغابات والصحارى والجليد والقلاع والبراكين.
- اجمع العملات من الجواهر وأكمل المراحل لكسب مكافآت إضافية.
- اشترِ السيوف السحرية (80 عملة) لضرب وحش مجاور، أو القنابل (130 عملة) لإصابة الوحوش القريبة. تُحفظ العملات والأدوات والتقدم محليًا.
